# Phase 0 — block-bootstrap CIs (paired model differences)

B=2000, seed=42, stationary block bootstrap over window-ids (mean block 3.0 windows). windows tile at 30-day steps; targets non-overlapping but temporally dependent via shared feature history + aftershock clustering -> block (not iid) resampling required.

Delta is defined as **(A − B)** for the listed pair; the reverse pair follows by symmetry (sign flip, win-rate → 1−w). Higher is better for PR-AUC / ROC-AUC / IG; lower is better for Brier. **Verdict** applies the pre-registered rule: A beats B iff the 95% CI excludes 0 (A-favouring) for BOTH IG and PR-AUC.
